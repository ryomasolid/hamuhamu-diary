Features

ハムスターのお世話を
もっとたのしく

📋

毎日の記録がサクッと

体重・エサ・お掃除・メモを1画面でまとめて入力。テンプレート登録でタップ1つ。

📷

写真つきで残せる

その日の様子を写真と一緒に記録。日記一覧でかわいい思い出をいつでも振り返れる。

🔔

お世話のサイクル管理

床材交換・フィルター交換などのリマインダーで、ケアの頻度を忘れず管理。

📤

同居人と共有できる

AirDropやLINEで日記データを丸ごと共有。写真も含めて完全転送、自動でマージ。

🌙

ダークモード対応

夜中のお世話確認もやさしい表示で。システムの設定に合わせて自動切替。

🔒

オフライン完結

データはすべて端末内に保存。アカウント登録不要、ネット接続なしで使える。

ふたりで育てても、
記録はひとつに 🐹

同居人それぞれのスマホで記録した日記を、AirDropで送り合うだけ。日付ごとに自動でマージされるから、同じ日の記録が重複することもありません。
